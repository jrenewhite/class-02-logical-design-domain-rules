# Evaluación de actividades - Clase 02

Este documento explica cómo se revisan las actividades de esta sesión.

## Modelo de puntos

Cada actividad evaluada usa este reparto:

```txt
Resultados:      4 puntos
Procedimiento:   2 puntos
Pregunta:        2 puntos
Total:           8 puntos
```

## Qué cuenta como resultados

En Clase 02, resultados significa que tu entrega:

- existe
- tiene la estructura solicitada
- contiene las secciones pedidas
- cumple el mínimo de entidades, relaciones o reglas
- pasa la validación pública

## Qué cuenta como procedimiento

Se observa sobre todo en `REPORT.md`.

Ahí esperamos ver:

- qué decisiones tomaste
- por qué elegiste ciertas entidades o reglas
- qué dudas tuviste
- qué revisarías antes de convertir esto a tablas reales

## Qué cuenta como pregunta

El instructor puede hacer una pregunta breve para validar comprensión.

Ejemplos:

- ¿por qué esto es entidad y no regla?
- ¿qué pasaría si ignoramos esta regla?
- ¿qué relación existe entre pedido y producto?
- ¿qué regla implementarías en base de datos?

## Qué valida el script

La validación pública revisa solo estructura mínima.

Por ejemplo:

- que exista `submission.md`
- que exista `REPORT.md`
- que el archivo no esté vacío
- que aparezcan las secciones obligatorias
- que haya suficientes entidades, relaciones o reglas

## Qué no valida el script

El script no revisa automáticamente:

- si tus entidades son las mejores posibles
- si tus relaciones están perfectamente justificadas
- si tus reglas capturan toda la complejidad del negocio
- si tu razonamiento técnico es sólido

Eso lo revisa el instructor.

## Mensaje importante

Pasar la validación pública **no garantiza la calificación completa**.

La validación pública sirve para comprobar que tu entrega es revisable.

La nota completa depende también de:

- claridad del `REPORT.md`
- calidad del razonamiento
- pregunta oral
- revisión conceptual del instructor

# Demo - FamilyMarket

La demo de Clase 02 existe para practicar una idea central:

**antes de diseñar tablas, entendamos el negocio.**

En esta carpeta vas a encontrar:

- `scenario.md`: el caso breve de FamilyMarket
- `domain-model.md`: cómo extraer entidades, relaciones y reglas
- `walkthrough.md`: recorrido paso a paso para la sesión

El foco de esta demo no es SQL complejo.
El foco es aprender a pasar de un problema de negocio a un modelo lógico defendible.

# Class Activity 01 - Entidades y relaciones

## Objetivo

Identificar entidades principales y relaciones razonables a partir del escenario de **FamilyMarket**.

## Pregunta guía

**¿Qué cosas necesita recordar o controlar el negocio, y cómo se conectan entre sí?**

## Qué debes hacer

Lee `../../demo/scenario.md` y completa:

- `submission.md`
- `REPORT.md`

## Entrega esperada

En `submission.md` debes incluir:

- sección `## Entidades`
- sección `## Relaciones`
- al menos 4 entidades no vacías
- al menos 3 relaciones no vacías

## Qué valida el script

La validación pública revisa:

- que exista `submission.md`
- que exista `REPORT.md`
- que ambos archivos no estén vacíos
- que estén las secciones solicitadas
- que haya al menos 4 entidades
- que haya al menos 3 relaciones

## Flujo recomendado

1. Lee `../../demo/scenario.md`.
2. Revisa `../../demo/domain-model.md`.
3. Llena `submission.md`.
4. Llena `REPORT.md`.
5. Corre:

```bash
check class-activity-01
```

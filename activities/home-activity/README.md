# Home Activity - Reglas extendidas y validaciones

## Objetivo

Extender el trabajo de la actividad 02 agregando más reglas y pensando posibles formas de implementación.

## Pregunta guía

**¿Cómo convertirías reglas de negocio en decisiones que protegen la calidad de los datos?**

## Qué debes hacer

Trabaja otra vez sobre **FamilyMarket**.

No uses todavía el proyecto final como entrega técnica.

Completa:

- `submission.md`
- `REPORT.md`

## Entrega esperada

En `submission.md` debes incluir:

- sección `## Reglas extendidas`
- sección `## Reflexión final`
- al menos 8 reglas no vacías

## Qué valida el script

La validación pública revisa:

- que exista `submission.md`
- que exista `REPORT.md`
- que ambos archivos no estén vacíos
- que estén las secciones solicitadas
- que haya al menos 8 reglas

## Flujo recomendado

1. Revisa tu Activity 02.
2. Agrega reglas nuevas o mejora las existentes.
3. Piensa cuáles vivirían en base de datos, aplicación o proceso.
4. Llena `submission.md`.
5. Llena `REPORT.md`.
6. Corre:

```bash
check home-activity
```

# Class Activity 02 - Reglas de dominio

## Objetivo

Tomar el mismo escenario de **FamilyMarket** y escribir reglas de negocio que protejan la operación y la calidad de los datos.

## Pregunta guía

**¿Qué condiciones debe respetar el sistema para evitar datos imposibles o decisiones incorrectas?**

## Qué debes hacer

Trabaja sobre el mismo escenario y completa:

- `submission.md`
- `REPORT.md`

## Entrega esperada

En `submission.md` debes incluir:

- sección `## Reglas`
- sección `## Regla más importante`
- al menos 5 reglas no vacías

## Qué valida el script

La validación pública revisa:

- que exista `submission.md`
- que exista `REPORT.md`
- que ambos archivos no estén vacíos
- que estén las secciones solicitadas
- que haya al menos 5 reglas

## Flujo recomendado

1. Relee `../../demo/scenario.md`.
2. Piensa qué errores quiere evitar el negocio.
3. Llena `submission.md`.
4. Llena `REPORT.md`.
5. Corre:

```bash
check class-activity-02
```

## Qué no se espera todavía

- triggers implementados
- restricciones físicas completas
- SQL avanzado
- una solución final del proyecto
